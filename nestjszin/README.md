# Cert Namo 💘

App prank para criar uma “certidão de namoro” online e compartilhar por link.

## Ideia

O casal informa nomes, data, foto, moldura e mensagem especial.

Depois recebe uma página pública tipo:

`/ver-certificado/maria-joao`

Futuro: perfil do casal, atividades, pontos, estrelas e disputa entre os dois.

## Stack

Vue + NestJS + PostgreSQL + Vercel CDN.
